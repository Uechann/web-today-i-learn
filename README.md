# Today I Learn (Uechann.github.io)

🚀 Today I Learn 페이지 만들기
⛳️ 학습 목표
웹 페이지가 어떻게 구성되어 있는지 이해한다.
HTML, CSS, JavaScript가 각각 어떤 역할을 하는지 알아본다.
HTML의 주요 태그를 활용하여 간단한 웹 페이지 구조를 잡을 수 있다.
CSS의 선택자와 레이아웃 속성을 활용하여 페이지를 꾸밀 수 있다.
JavaScript로 DOM을 제어하고 이벤트 리스너를 활용할 수 있다.
실습 환경 구축
web-today-i-learn 저장소를 자신의 계정으로 Fork 한 뒤, 로컬에 Clone하여 미션을 진행한다.

1단계 - HTML로 뼈대 잡기
기능 요구사항
image.png

프로필 영역
나를 가장 잘 소개하는 사진(<img>)과 닉네임, 한 줄 소개를 구성한다.
기본 정보
이름, MBTI, 취미, 좋아하는 음식 등 자신의 기본 정보를 표(<table>) 로 정리한다.
자기소개
자신을 소개하는 글을 단락(<p>)으로 작성한다.
소개 글 안에 관련 링크(블로그, GitHub 등)를 <a> 태그로 연결한다.
나만의 갤러리
부제를 구성하고 그에 알맞은 9가지 사진을 정사각형으로 배치한다.
예시) 기억에 남는 여행지 / 내가 좋아하는 요리 / 다이어트 식단 / 오운완 등 자유 주제로 선정한다.
나를 울린 인생 작품
최소 2가지를 목록(<ul> 또는 <ol>) 형태로 소개한다.
작품 중 하나는 관련 영상(트레일러, 뮤직비디오 등)을 <video> 또는 <iframe> 태그로 삽입한다.
예시) 인생 영화, 인생 노래, 인생 책, 인생 드라마 등 자유 주제로 선정한다.
TIL (Today I Learned)
오늘 새롭게 배운 내용을 기록하는 섹션을 구성한다.
날짜, 학습 주제, 내용을 포함한다.
상단 내비게이션
각 섹션으로 이동할 수 있도록 <a> 태그로 페이지 내 하이퍼링크를 설정한다.
요구사항에 나와 있지 않은 내용은 스스로 판단하여 구현한다.
프로그래밍 요구사항
root 디렉터리에는 웹 문서만 저장할 수 있다.
HTML 인코딩은 UTF-8 방식을 이용한다.
<head> 태그 안에 <meta charset="utf-8"> 코드를 삽입한다.
<meta name="viewport" content="initial-scale=1, width=device-width"> 를 삽입한다.
<title> 태그 안에 적절한 제목을 재량껏 고민하여 삽입한다.
Open Graph 메타 태그(og:title, og:description, og:image)를 최소 1개 이상 설정한다.
웹 문서를 구성할 때는 시멘틱 태그(<header>, <nav>, <main>, <section>, <article>, <footer>)를 적절히 활용한다.
웹 문서의 본문 영역은 <h1> ~ <h6> 태그를 사용하여 제목 계층 구조를 지킨다.
<img> 태그에는 반드시 alt 속성을 작성한다.
리소스를 불러오는 경로는 상대 경로로 지정해야 한다.
images 디렉터리에는 이미지 파일만 저장할 수 있다.
css 디렉터리에는 스타일링 파일만 저장할 수 있다.
2단계 - CSS로 꾸미기
기능 요구사항
CSS는 별도 파일(.css)로 분리하여 <link> 태그로 연결한다.
선택자를 활용하여 스타일을 적용한다.
태그 선택자, 클래스 선택자(.), ID 선택자(#)를 각각 1회 이상 사용한다.
나만의 갤러리 이미지 9장을 CSS Grid 또는 Flexbox를 활용하여 보기 좋게 배치한다.
레이아웃은 제공되는 템플릿 파일을 따르되, 본인이 원하는 대로 자유롭게 스타일링할 수 있다.
3단계 - JavaScript로 동작 추가
기능 요구사항
JavaScript는 별도 파일(.js)로 분리하여 <script> 태그로 연결한다.
TIL 섹션에 작성 폼을 추가한다.
<form> 태그 안에 날짜(<input>), 제목(<input>), 내용(<textarea>)을 구성한다.
각 입력 요소에는 <label> 태그를 연결한다.
등록 버튼(<button>)을 클릭하면 이벤트 리스너로 입력 내용을 받아 TIL 목록에 추가한다.
document.querySelector() 등을 활용하여 DOM 요소를 선택하고 제어한다.
기본 요구사항을 모두 충족시켰다면, 그 이외의 기능을 추가하는 것도 허용한다.
예시) 다크 모드 토글, 갤러리 이미지 클릭 시 확대, 내비게이션 스크롤 애니메이션 등
4단계 - 배포 및 공유
GitHub Pages를 통해 배포한다.
또는, 다른 배포 플랫폼을 이용하여 웹 사이트 링크로 공유할 수 있다면 어떤 방식으로도 허용한다.
자신이 작성한 홈페이지를 서로 공유한다.
자신이 새롭게 배운 개념(HTML, CSS, JavaScript)도 함께 공유한다.
생각해 보기
HTML
나만의 갤러리에서 사진 9장은 HTML 태그 중 어떤 요소로 표현하는 것이 좋을까? 이유는 뭐라고 생각했는가?
뼈대 코드를 기반으로 이미지를 로드하는 방식은 크게 2가지로 나뉘는데 무엇이고 어떻게 사용하고 있는가?
시맨틱 태그(예: <header>, <main>, <section>, <footer> 등)로 문서를 구분할 때, 어떤 기준으로 섹션을 나누고 태그를 적용하는 것이 좋을까?
<img> 태그의 alt 속성은 왜 필요하며, 어떻게 작성하는 것이 좋을까?
이미지를 로드할 때, 상대 경로(relative path)와 절대 경로(absolute path)를 혼용하면 어떤 문제가 발생할 수 있을까?
<meta> 태그의 viewport 설정과 Open Graph 태그는 각각 어떤 역할을 하는가?
CSS
나만의 갤러리에서 9장의 이미지를 보기 좋게 배치하려면, Flexbox와 CSS Grid 중 어떤 것이 더 적합할까? 그 이유는?
태그 선택자, 클래스 선택자, ID 선택자는 각각 언제 사용하는 것이 적절할까?
CSS를 HTML 내에 직접 작성하는 것과 별도 파일로 분리하는 것의 차이는 무엇일까?
JavaScript
document.getElementById()와 document.querySelector()의 차이는 무엇인가?
이벤트 리스너를 사용해서 "어떤 일이 일어났을 때 어떤 동작을 실행"하게 만들 수 있다. 자기소개 페이지에서 활용할 수 있는 이벤트에는 어떤 것들이 있을까?
innerHTML로 DOM을 조작할 때 주의해야 할 점은 무엇일까?
배포
GitHub Pages로 배포한 페이지에서 TIL을 작성하면, 새로고침하거나 재배포했을 때 데이터가 유지될까? 그 이유는?
JavaScript로 추가한 데이터를 영구적으로 저장하려면 어떤 방법이 있을까?
